# Rolês em SP — Gemini CLI extension

Extensão apenas de metadados: aponta o Gemini CLI para o conector MCP remoto `https://rolesemsp.com.br/mcp` (OAuth). Não contém código do servidor, catálogo, embeddings nem prompts internos.

```
gemini extensions install https://github.com/DanRioDev/roles-em-sp-gemini
```

Depois, dentro do Gemini CLI: `/mcp auth roles-em-sp`.

Site: https://rolesemsp.com.br/
