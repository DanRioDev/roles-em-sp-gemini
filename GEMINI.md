# Rolês em SP

Conector remoto para sugerir rolês culturais em São Paulo. O catálogo fica no servidor: esta extensão só aponta para ele.

- Autentique com `/mcp auth roles-em-sp` antes do primeiro uso.
- Use as ferramentas do servidor para recuperar candidatos; confirme funcionamento/programação atuais na web antes de recomendar.
- Respeite restrições alimentares e orçamento do usuário antes de ranquear.
- Não tente listar ou exportar o catálogo; as ferramentas retornam apenas resultados limitados por consulta.
